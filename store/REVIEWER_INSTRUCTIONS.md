# Private reviewer instructions

FlowRead is an independent GPL fork. Contact admin@4dv.top. No FlowRead login/subscription. AI features require your OpenAI API key, model access and usage charges, separate from ChatGPT. Request a private temporary review key from the publisher if needed; none is bundled.

1. Install ZIP, open Options → API Providers, read processing/fee/PDF disclosure and privacy link. Save key, Test connection. Processing uses fixed OpenAI endpoints; Microsoft TTS/hosted services/telemetry/CDN code are disabled.
2. Select English text on HTML → FlowRead Translate. Check expanded audio, dictionary, vocabulary save. Page translation is explicit except user-enabled automatic site rules.
3. Open PDF reader, choose a local PDF. Search/zoom/outline/notes/drawing/bookmarks/resume work without a key. Enable Song ngữ theo đoạn and explicitly translate a paragraph/range. Scan OCR can be local or opt-in OpenAI crop OCR. Original PDF binary is never uploaded.
4. On YouTube with native CC, open FlowRead's subtitle menu. Enable subtitles. Lồng tiếng OpenAI reads original/translated captions with preset AI voice, ducked original volume, live volume/offset controls. ani.pm needs SOFT native CC, not HARD burned-in text. Netflix needs the user's subscription/native captions; no DRM bypass.
5. AI phụ đề và giọng đọc → Tự phân tích khi xem → explicitly enable. Keep a captioned video playing. About 15 seconds of played audio is sampled without seeking/pausing/microphone; OpenAI supplies context/speaker slots. Once per new ten-minute part, no failed paid automatic retry. Unknown/unheard speakers keep baseline voice. Cancel/off stops future samples. Restricted players fail clearly without downloads/bypass/paid fallback.
6. Alternative Chuẩn bị trước mode explicitly pre-records video up to ten minutes (or uses selected matching MP3/WAV≤8MiB), waits, then analyzes. It restores owned position/rate paused; it is not a remote video downloader. Automatic mode needs no file.
7. Audio → Văn bản: explicitly choose tab, record-first/live; keep regular Audio page open while multitasking. Source pane is movable/pinnable. Contextual final-only translation is separate opt-in. Timed file subtitles require validated API timestamps. Merely opening the tool starts no capture.
8. English selection → Phát âm → practice page; allow microphone, record, explicitly grade. Conservative half-step feedback/retry. Local shadowing elsewhere is not uploaded.
9. Named vocabulary notebooks support review/export/mobile HTML and per-word logs. Optional Edge config sync excludes keys/notebooks/audio/PDF data.
