# Installation identity and data

Local installation stays at `C:\Users\TIEN\Downloads\ReadFrog-Edge-1.58.0A`. Validated ZIPs are staged separately, copied assets first and manifest last, then hashes verified. Reload the same entry; no reinstall/profile writes/destination cleanup.

A new store item receives its own ID and **does not automatically inherit unpacked data**. Do not impersonate the assigned store ID by changing the local manifest key. Keep the old installation/profile until needed data is verified.

Before moving, export supported settings (without key), each notebook/progress, passage library and supported pronunciation/reports; retain original and annotated PDFs. Exports are feature-specific: PDF sidecar workspace/bookmarks/resume and every cache are not universally backed up. Enter the key again securely; grant file/site/microphone access as needed. Avoid both extensions translating/capturing the same tab.

Future own-store links/manual migration tools need a tested follow-up. This package claims no automatic cross-ID migration. Normal updates of the same store ID preserve its local browser data subject to browser behavior.
