# Data forms — owner checklist

Read `../PRIVACY_POLICY.md` before attesting. Chrome requires disclosures for local handling too: **do not claim no data handled**. No ads, sale, creditworthiness, unrelated profiling or developer telemetry.

| Category                            | Prepared disclosure                                                                                                                                                                      |
| ----------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Website content                     | Yes: text/captions, chosen images, PDF text/crops and audio. Local cache; enabled AI sends necessary content directly to OpenAI. PDF binary never uploaded.                              |
| Authentication information          | Yes: API key local, sent only as OpenAI authorization; excluded from config sync/export.                                                                                                 |
| Web history / URLs                  | Yes: local source URL/title, document history/resume/ownership. No server browsing history. Native source GETs use source URLs; feature guards exclude paths/URLs from provider content. |
| User activity                       | Yes: local learning answers/progress, usage counters and reading/practice actions; user-exported reports, no ad analytics.                                                               |
| Personal communications             | User-selected meeting audio or communication text can be processed. No automatic inbox/contact access.                                                                                   |
| Personally identifiable information | Chosen text/title/audio can contain personal information; no FlowRead profile or requested legal identity. Support messages are intentionally sent separately.                           |
| Health, financial, location         | No dedicated collection/inference. Arbitrary chosen content may contain sensitive data; describe under content rather than promise filtering. Confirm current form wording.              |

OpenAI is the content processor with its own retention terms/usage fees. Native caption/PDF-source GETs go to source sites. Optional Edge config sync uses Microsoft infrastructure. No FlowRead processing backend. HTTPS/WSS protects provider transit; do not claim encrypted-at-rest local storage.

API Providers settings shows direct-processing/fee/PDF disclosures before key entry and links bundled policy. AI/capture/automatic modes have opt-in controls. No silent microphone, paid fallback or paid automatic repair. Stop cancels future owned work, not an upload already sent. The owner must certify limited-use obligations; this is not a submitted declaration.
